The project is an implementation of an H-bridge driving IC DRV8702QRHBRQ1 that allows control of full H-bridge motor driver in different modes.
The ECU includes:
- buttons for manual control of the motor in both direction + braking
- Status LED
- ON/OFF switch
- Interface for banana plugs and probes
- Interface for electrical control

A chassis designed for 3D printing that protects the ECU. It is inteded to be printed from 3 pieces:
- 2x hard plastic shell (PLA, ABS, ...)
- 1x soft shell for protection against bumps (TPA)
